# ADR-0004: Proyecto como carpeta JSON + assets, empaquetable en `.wpe`

- Estado: propuesto
- Fecha: 2026-10-07

## Decisión
Datos en JSON legible y versionado (diff-friendly, compatible con git); export a pack binario para el player.

## Consecuencias
+ Fácil de editar y versionar. − Más tamaño que binario (mitigado en export).
